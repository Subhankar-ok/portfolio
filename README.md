# Personal Portfolio Website

This is my personal portfolio website showcasing my skills, projects, certifications, and experience.
It is built using HTML, CSS, Bootstrap, and JavaScript, and is fully responsive for all devices.

## 🚀 Live Demo

🔗 [View on Netlify](https://subhanakar-okhb.netlify.app/)  
🔗 [View on GitHub Pages](https://github.com/Subhankar-ok/portfolio.git)

## 🚀 Features

📱 Fully responsive design for mobile, tablet, and desktop

🖥️ Clean and modern UI with smooth scrolling

📂 Project showcase with descriptions and GitHub/demo links

📜 Downloadable resume section

🌐 Social media and contact information included in footer

🏷️ Multi-section layout: About, Skills, Certifications, Academic Details, Projects, Contact

## 🛠️ Tech Stack

HTML5

CSS3

Bootstrap 5

JavaScript
